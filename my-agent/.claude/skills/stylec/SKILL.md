# 스타일씨 체험단

## 조건 (강현님이 바꾸면 이 표를 업데이트)
| 항목 | 값 |
|---|---|
| 채널 | 블로그 shop4uu.tistory.com / todayshopping.tistory.com (캠페인 성격에 맞는 쪽으로 신청, 애매하면 질문) |
| 선호 카테고리 | 생활·주방·가전·리빙 (미정이면 강현님께 확인) |
| 제외 | 이미 신청한 캠페인, 마감 지난 캠페인 |

## 1. 새 캠페인 찾기
1. 스타일씨 사이트에서 로그인 상태 확인 (안 돼 있으면 로그인 요청). 정확한 주소를 모르면 강현님께 물어 이 파일에 적어 둡니다.
2. 블로그 체험단 목록에서 모집 중인 캠페인을 훑어봅니다.
3. 각 캠페인: 제목, 제공 내역(제품/금액), 모집 인원·신청 수, 신청 마감, 발표일, 리뷰 마감, 미션(필수 키워드·사진 수 등), URL
4. 이미 기록된 캠페인은 건너뜁니다: `python3 tools/tracker.py campaigns --platform stylec`

## 2. 추천 보내기 (텔레그램)
조건에 맞는 것 최대 5개를 번호 목록으로: `1) 제목 · 제공내역 · 신청 마감 · 경쟁률`
"신청할 번호 알려주세요"로 끝냅니다. **답 받기 전에는 신청하지 않습니다.**

## 3. 신청
1. 고른 캠페인의 신청 화면 → 신청서 항목 확인
2. 자기소개·신청 사유 같은 서술 항목은 블로그 성격에 맞게 초안을 쓰고, 미션 동의 항목이 있으면 그 내용을 요약해 강현님께 보여 준 뒤 승인 받고 제출
3. 기록:
   `python3 tools/tracker.py campaign-add --platform stylec --title "<제목>" --url <URL> --reward "<제공내역>" --apply-deadline YYYY-MM-DD --announce-date YYYY-MM-DD --review-deadline YYYY-MM-DD --status applied`

## 4. 발표 확인
정기 확인 때 신청한 캠페인의 선정 여부를 확인해 `campaign-update <ID> --status selected|rejected`.
선정되면 리뷰 마감일과 미션을 텔레그램으로 알려 줍니다.

## 주의
- 사이트 약관상 자동 대량 신청이 금지일 수 있어, 한 번에 몇 개씩 사람처럼 천천히 진행합니다.
- 선정 후 작성하는 글에는 협찬 문구를 넣습니다 (`blog-post` 스킬).

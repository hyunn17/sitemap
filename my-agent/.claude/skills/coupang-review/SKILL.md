# 쿠팡 리뷰 작성

## 원칙
쿠팡 리뷰는 **강현님 계정으로 실제 구매한 상품**에만 씁니다. 내용은 강현님이 준 경험(메모·사진·별점)만으로
쓰고, 메모에 없는 사용 경험을 지어내지 않습니다. 쿠팡 정책상 허위 리뷰는 리뷰 삭제·계정 제재 대상입니다.

## 1. 작성할 리뷰 찾기
1. 쿠팡 → 마이쿠팡 → 리뷰 관리 → **작성 가능한 리뷰** 목록 확인 (로그인 안 돼 있으면 요청)
2. 텔레그램으로 목록 보내기: `1) 상품명 · 구매일`
3. "리뷰 쓸 상품 번호와, 써보니 어땠는지 한두 줄 + 별점 + (있으면) 사진 보내 주세요"

## 2. 초안
- 강현님 메모를 자연스러운 문장으로 다듬습니다 (200~500자, 장점·아쉬운 점·추천 대상).
- 강현님 말투(반말/존댓말, 이모지 여부)를 살립니다.
- 설문 항목(사이즈, 만족도 등)이 있으면 메모에서 답을 고르고, 알 수 없는 항목은 물어봅니다.
- 체험단·무상 제공 상품이면 쿠팡 리뷰 정책에 따라 그 사실을 밝힙니다.

## 3. 승인 → 등록
1. 텔레그램으로 초안 + 별점 + 첨부할 사진 수를 보여 주고 승인 요청
2. 승인되면 리뷰 작성 화면에서 별점·설문·본문 입력, 사진 업로드 후 등록
3. 기록: `python3 tools/tracker.py review-add --product "<상품명>" --rating <1-5> --status posted`
4. 텔레그램으로 "등록 완료" 보고

# 블로그 글 작성·발행

함께 읽을 파일:
- `style-guide.md` — 사람이 쓴 것 같은 문체, 금지어, 5대 법칙, 공정위 문구 (**집필 전에 반드시 읽기**)
- `templates.md` — 유형별 구성
- `html-snippets.md` — 버튼·이미지·유튜브·경고 박스 HTML

## 1. 요청 정리
요청에서 아래를 채우고, 빠진 것만 한 번에 묻습니다.
- 블로그(`shop4uu` / `todayshopping`) / 주제 / 대상 제품 / 유형(`vs`, `top`, `review`, `tip`) / 핵심 강조점
- **강현님이 실제 쓰는 제품은 어느 것인지** (사진이 있으면 그 제품)
- 발행 방식: 즉시 / 예약(날짜·시각) / 임시저장만

## 2. 조사 (브라우저)
- 쿠팡 상품 페이지: 현재 판매가, 스펙, 구성품, 구매자 리뷰에서 반복되는 구체적 체감 포인트
- 제조사 공식몰: 정확한 스펙·치수·소비전력, 공식 이미지
- 다나와 등으로 가격 이력 확인 → 단종 프리미엄·구형 역전 가격이면 경고 박스 소재
- 유튜브에서 신뢰할 만한 실측 비교 영상 1개
- 메모는 `posts/<파일명>.md`에 출처 URL과 함께 저장

## 3. 경험 체크리스트 (강현님이 쓰는 제품이 있을 때, 강현님 시간 10초)
1. 구매자 리뷰·강현님 사진에서 실사용자만 아는 구체적 경험 8~12개를 뽑습니다
   (오감 디테일 위주: 소리, 촉감, 냄새, 불빛, 설치/관리 수고, 계절·상황별 체감, 장점과 단점 섞어서).
2. 텔레그램으로 번호 목록을 보냅니다:
   ```
   강현님 경험과 맞는 걸 골라 주세요 👇
   1) 첫날 플라스틱 냄새 → 하루 환기하니 사라짐
   2) 강 모드는 드라이기 약풍 정도 소리
   3) 등 쪽에 열선 느낌 전혀 없음
   ...
   "다 맞아" / "1,2,5" / "3번은 반대" 처럼 답해 주세요. (사용 기간·구매가도 알려 주시면 넣을게요)
   ```
3. 고른 항목만 1인칭 체험으로 씁니다. 고친 내용은 고친 대로. 안 고른 항목은 버립니다.
4. 강현님이 안 쓴 제품은 체크리스트 없이 **사실형**으로 씁니다 (style-guide 2번).

## 4. 집필
- `style-guide.md` 규칙대로 `posts/YYYY-MM-DD-슬러그.html`에 티스토리 HTML 본문 작성 (공백 제외 5,000자 이상)
- 공정위 문구 박스는 글 성격(실사용/비사용/체험단)에 맞는 버전으로, 매번 어휘 변주
- 제휴 링크: 강현님이 준 링크, 없으면 쿠팡 파트너스에서 제품별 단축 링크 발급 → 모델별 버튼 3단 배치
- 제목 1개 + 대안 2개, 태그 8개, 카테고리 제안
- 다 쓴 뒤 금지어 자체 점검: "구매평", "리뷰 N건", "%", "통계", "알아보겠습니다", "도움이 되셨길", "다를 수 있" 이 남아 있으면 고치기

기록: `python3 tools/tracker.py post-add --type <유형> --title "<제목>" --file posts/<파일>.html`

## 5. 썸네일과 본문 이미지 (`posts/<슬러그>/` 폴더에 저장)
**썸네일**
```bash
python3 tools/thumbnail.py "1행" "2행" "3행" --brand 쇼핑포유 -o posts/<슬러그>/thumb.png
```
행당 4~6자 권장. 결과를 직접 열어 글자 잘림이 없는지 확인합니다.

**상세페이지 캡처** — 소제목마다 설명에 맞는 부분을 찾아 자르기
1. 쿠팡 상세페이지에서 상세 이미지 URL을 찾습니다 (상세 영역 `<img>`의 src, 대부분 세로로 긴 이미지).
2. `python3 tools/crop_image.py <URL> --info` 로 크기 확인 → 브라우저 화면에서 필요한 부분의 위치를 보고 범위 지정:
   `python3 tools/crop_image.py <URL> -o posts/<슬러그>/detail-1.jpg --top 2400 --bottom 3300`
3. 잘린 결과를 열어 보고 글자가 잘렸으면 범위를 조정합니다.
4. 이미지 URL을 못 찾는 상세페이지는 브라우저 스크린샷으로 대신합니다.

**실사 연출 이미지 (Codex CLI)** — 실사진이 부족한 소제목에만
```bash
tools/codex-image.sh -o posts/<슬러그>/scene-1.png -i posts/<슬러그>/product.jpg \
  -p "아늑한 침실 퀸 침대 위에 깔린 카본매트, 저녁 간접조명, 자연스러운 생활 사진"
```
- `-i` 상품 대표 이미지(쿠팡 상품 이미지 저장)로 제품 모양·색을 맞춥니다.
- 결과를 직접 열어 제품이 원본과 다르게 그려졌거나(버튼·로고·색 변형) 어색하면 다시 생성하거나 버립니다.
- Codex 실패 시 2번까지 재시도, 그래도 안 되면 상세페이지 캡처로 대체하고 텔레그램에 알립니다.
- 캡션 규칙은 `style-guide.md` 6번.

## 6. 티스토리에 임시저장 (브라우저)
1. `https://<블로그>.tistory.com/manage/newpost` 열기 (`shop4uu` 또는 `todayshopping`, 로그인 안 돼 있으면 강현님께 요청)
2. 기본모드 → **HTML** 모드 전환 (확인 대화상자 수락)
3. 에디터에 원고 넣기. 붙여넣기가 잘 안 되면 페이지에서 실행:
   ```javascript
   const cm = document.querySelector('.CodeMirror').CodeMirror;
   cm.setValue(htmlContent); cm.focus();
   ```
   이후 Space → Backspace 를 한 번 입력해 변경 사항이 반영되게 합니다.
4. **기본모드**로 돌아와 본문이 제대로 보이는지 확인
5. 썸네일·실사진 업로드(사진 첨부) → 대표 이미지를 썸네일로 지정
6. 제목, 카테고리, 태그 8개 입력
7. 하단 **[저장]**(임시저장) → "작성 중인 글이 저장되었습니다" 확인

## 7. 승인 요청 (텔레그램)
제목, 유형, 3줄 요약, 썸네일 이미지, 발행 방식을 보내고 승인 요청합니다. 원고 전체가 필요하면 html 파일 첨부.
수정 요청이 오면 반영 후 다시 임시저장 → 재승인.

## 8. 발행
승인 후:
1. 임시저장 글 열기 → [완료] → 공개 + (예약이면 날짜·시각) → [발행]
2. **보안문자(캡차)가 뜨면** 화면을 캡처해 텔레그램으로 보내고 강현님이 처리하도록 기다립니다.
   (또는 강현님이 휴대폰 티스토리 앱에서 임시저장 글을 직접 발행해도 됩니다. 이 경우 "발행하셨으면 알려 주세요"라고 남기기)
3. 발행 URL 확인 → `python3 tools/tracker.py post-update <ID> --status published --url <URL>`
   (예약이면 `--status scheduled --scheduled-at "YYYY-MM-DD HH:MM"`)
4. 텔레그램에 "발행 완료 + 링크" 보고 → `index-request` 스킬로 색인 요청 (예약 글은 발행 시각 이후에)

## 실패 시
에디터 구조가 바뀌어 버튼을 못 찾으면 스크린샷을 보내고 멈춥니다. 추측으로 다른 버튼을 누르지 않습니다.

# 글 유형별 구조

공통: 도입 2~3문장(검색 의도에 바로 답) → 본문 → 결론(누구에게 추천/비추천) → 관련 글 링크.
파트너스 링크가 있으면 맨 위에 공정위 문구. 체험단이면 협찬 문구.

## vs — A vs B 비교
- 제목 예: `카본매트 vs 온수매트 비교｜전기세·전자파·관리 차이 정리`
1. 한눈에 비교표 (가격, 핵심 스펙, 장점, 단점, 추천 대상)
2. 항목별 비교 3~5개 (예: 전기세, 안전성, 관리 편의, 소음)
3. 구매자 후기에서 자주 나온 이야기 (출처 드러나게)
4. 상황별 추천: "이런 분은 A, 이런 분은 B"

## top — TOP 3·5 추천
- 제목 예: `2026 가성비 전기요 TOP 5｜가격대별 추천`
1. 고르는 기준 3가지
2. 제품별 카드: 한 줄 요약, 장점 2, 아쉬운 점 1, 추천 대상, 링크
3. 한눈에 비교표
4. 결론: 예산별 최종 추천

## review — 1개 제품 실사용 후기 (실제 사용한 제품만)
- 제목 예: `[내돈내산] ○○ 3개월 사용 후기｜장단점 솔직하게`
- 강현님이 준 경험 메모·사진만으로 "경험" 부분을 씁니다. 메모에 없는 경험을 추가하지 않습니다.
1. 구매 이유와 구매 정보(가격·구매처·사용 기간)
2. 언박싱/첫인상 (사진)
3. 실제 써보니 좋았던 점 / 아쉬운 점
4. 추천 대상, 비추천 대상
5. (선택) 다른 구매자들 평가와 비교 — 출처 드러나게

## tip — 정보성 꿀팁
- 제목 예: `전기장판 전기세 아끼는 법 7가지｜실제 계산해봄`
1. 핵심 답 요약 (3줄)
2. 방법/팁 번호 목록, 각 2~4문장 + 근거
3. 자주 묻는 질문 3개
4. 관련 제품이 자연스러울 때만 링크 (억지 삽입 금지)

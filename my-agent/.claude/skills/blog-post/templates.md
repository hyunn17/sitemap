# 글 유형별 구성

문체·금지어·공정위 문구는 `style-guide.md`, HTML 조각은 `html-snippets.md`.
공통: 공정위 박스 → 도입부 → (도입부 직후 버튼) → 본문 → 결론 → 결론 직후 버튼. 공백 제외 5,000자 이상.

## vs — 1:1 라이벌 심층 비교 (예: 카본매트 vs 온수매트)
1. 도입부: 기존 제품 쓰며 겪은 현실적인 불편 에피소드 → 갈아탄 계기 (강현님 경험이면 체크리스트 기반)
2. 상단 빠른 바로가기 버튼 (두 모델 각각)
3. 핵심 체감 비교 4~5가지: 소음, 착용감/배김, 예열 속도, 관리, 유지비 등 — 각 H3를 Q&A 단답형으로
4. 한눈에 보는 스펙·가격 비교표
5. 솔직한 단점 2~3가지
6. 결론: "A를 추천하는 사람 vs B를 추천하는 사람"
7. 하단 모델별 버튼

## top — 3대장 / TOP 5 추천 (예: 가정용 온풍기 TOP 3)
1. 도입부: 계절·생활 문제로 구매를 고민하게 된 배경
2. 구매 전 필수 체크포인트 3가지 (전기세, 소음, 실효성 등)
3. 1위~3위 개별 리뷰: 체감 장단점 + **섹션 끝 전용 버튼**
   (강현님이 실제 쓴 모델만 1인칭, 나머지는 사실형 — style-guide 2번)
4. 종합 비교 표 (가격, 스펙, 추천 용도)
5. 전기요금/유지비 계산표
6. 최종 추천 요약

## review — 단일 제품 실사용기 (강현님이 실제 쓴 제품, 실사진 필수)
1. 구매 계기 + 구매 정보(가격·구매처·사용 기간)
2. 언박싱/첫인상 (실사진, 오감)
3. Q&A 단답형 H3 4~6개: 실제 써보니 좋았던 점 / 거슬린 점 (체크리스트 확인 항목)
4. 스펙·가격표, 필요하면 "지금 사면 손해" 경고 박스
5. 추천/비추천 대상
6. 하단 버튼

## tip — 정보성 꿀팁 (예: 전기장판 전기세 아끼는 법 7가지)
1. 첫 문단에 핵심 답 3줄
2. 번호 팁 목록, 각 팁 = 결론 한 줄 + 근거·계산
3. 계산표(전기요금 등)
4. 자주 묻는 질문 3개 (Q&A 단답형)
5. 관련 제품이 자연스러울 때만 버튼
